about=G-CHAM Data Pack Builder automates the creation of GIS-based Community Health Assessment Methods (G-CHAM) data packs for Japan. It downloads and integrates six 2020 Population Census 250 m mesh tables, 2026 N03 administrative boundaries, facility and transport datasets from National Land Numerical Information, GSI designated evacuation-site/shelter data, and J-SHIS probabilistic seismic-hazard information, and can add OpenStreetMap/GSI basemaps. Generated vector data are written as FlatGeobuf in the selected prefecture's JGD2011 Japan Plane Rectangular Coordinate System. The plugin handles Census suppression/aggregation, municipality allocation, derived age-group percentages, styling, labels, caching, and layer grouping. Road data are optional and disabled by default because downloads can be large. Spatial coverage is Japan. Internet access is required for source downloads and online map services. No external Python packages, API keys, user accounts, or personal information are required.
