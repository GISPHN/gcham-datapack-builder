# Security Policy

## Supported version

The current public release is supported for security fixes where technically practical.

| Version | Supported |
|---|---|
| 1.0.x | Yes |
| < 1.0 | No |

## Reporting a vulnerability

Please do not disclose a suspected security vulnerability in a public GitHub issue.

Report it directly to:

ryo.horiike@naramed-u.ac.jp

Include the affected plugin version, QGIS version, operating system, reproduction steps, and the smallest practical proof of concept. Do not send personal or confidential data that are not required to reproduce the problem.

## Network and data handling

The plugin downloads public government datasets from e-Stat and the National Land Numerical Information service. It does not require an API key or user account and does not intentionally transmit locally created GIS data to those services.
